# Twitch Chat Media Preview

Показывает превью изображений, видео и YouTube прямо в чате Twitch.

Поддерживаются:

* kappa.lol
* Imgur
* Gyazo
* Lightshot (prnt.sc)
* ibb.co
* прямые ссылки на изображения
* прямые ссылки на видео
* YouTube (карточка с предпросмотром и встроенным плеером)

## Установка

### 1. Установите Tampermonkey

* Chrome: https://tampermonkey.net/?ext=dhdg&browser=chrome
* Firefox: https://tampermonkey.net/?ext=dhdg&browser=firefox
* Edge: https://tampermonkey.net/?ext=dhdg&browser=edge

### 2. Установите скрипт

Нажмите:

➡ **[Установить скрипт](https://github.com/KittenWo0f/twitch-chat-media-preview/raw/refs/heads/main/twitch-chat-media-preview.user.js)**

Tampermonkey автоматически откроет окно установки.

## Обновления

Скрипт обновляется автоматически через Tampermonkey.

При выходе новой версии обновление будет предложено автоматически либо установится согласно настройкам Tampermonkey.

## Возможности

* предпросмотр изображений прямо в чате
* просмотр GIF и WEBP
* воспроизведение видео
* встроенный просмотр YouTube
* увеличение изображений по клику
* поддержка нескольких ссылок в одном сообщении
* лёгкий и быстрый интерфейс

## Совместимость

* Twitch
* Twitch Dashboard
* Tampermonkey
* Chrome
* Firefox
* Edge
